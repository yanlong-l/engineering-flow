# 工作流、配置与可插拔扩展

## 默认流程

用户安装后可以直接使用一条完整流程：取得上下文 → 实现 → 验证 → 准备 Review → 修订 → 交接。

允许从已有代码变更直接进入 Review，或从旧任务继续工作。系统先检查是否有足够信息；缺少原始需求时如实说明，不伪造开发意图。

只有当前阶段需要的内部模块进入模型上下文，避免每次加载所有 Skills。用户可以明确选择特定流程，但不需要知道内部 Skill 名称。

## 预设

| 候选预设 | 适用情况 | 差异 |
| --- | --- | --- |
| quick | 小型局部改动 | 简短记录和页面，保留必需检查 |
| standard | 一般功能开发 | 默认开发、检查、Review 与交接流程 |
| extended | 跨模块或状态复杂的改动 | 增加设计说明和相关专项检查 |

预设控制说明和可选步骤的深度，不能把跳过的必需检查变为通过。系统根据需求及实际改动提出建议，工程师可以调整。

## 配置层次

产品默认值 → 团队与项目配置 → 个人展示偏好 → 当前任务选项。

并非所有字段都允许后级覆盖。项目规定的必需检查，与个人语言、显示长度分属不同字段；个人偏好不能悄悄修改必需项。

本地可变配置本身不能保证公司制度被强制执行。真正需要落实的合并要求，应由适用的 CI 或仓库规则检查实际结果。

## 候选配置示例

下面用于讨论配置体验，尚不是已实现或可直接使用的配置格式。命令仅为示例，应按试点项目替换。

```json
{
  "schemaVersion": 1,
  "workflow": "standard",
  "checks": [
    {
      "id": "unit-tests",
      "command": "npm",
      "args": ["test"],
      "required": true,
      "timeoutSeconds": 300
    }
  ],
  "review": {
    "focus": ["authorization", "retries", "state-transitions"]
  },
  "documentation": {
    "styleModule": "engineer-voice",
    "updateMode": "propose"
  },
  "memory": {
    "loadRelevantOnly": true
  },
  "ui": {
    "language": "zh-CN"
  }
}
```

配置应通过 schema 验证。未知关键字段、冲突的必需项、缺失依赖均有诊断，不静默丢弃。配置版本和检查定义变化后，相关旧结果需要重新判断是否适用。

## 扩展接口

每个模块声明：ID、版本、适用阶段、输入与输出 schema、触发条件、依赖、所需能力、超时、失败处理和可否跳过。

| 字段 | 示例 |
| --- | --- |
| 模块 | 数据库变更检查 |
| 触发条件 | 任务涉及迁移或数据结构变更 |
| 输入 | 任务、快照、相关 diff 和项目配置 |
| 输出 | 迁移说明建议、真实检查记录、待确认事项 |
| 失败行为 | 显示模块错误，保留已有材料，不假报通过 |

先实现少量内置模块，再开放第三方模块接口；不先建设 Skill 商城或复杂插件依赖系统。

## 可扩展的场景

- 后端：权限、接口兼容、重试、并发与任务状态。
- 前端：加载、失败提示、重复操作、接口状态显示。
- 测试平台：设备占用、执行取消、运行记录与日志关联。
- 技术文档：README、设计决定、发布说明、排查手册。
- 后期外部连接：测试平台、CI、Jira 等。

外部读写能力分开定义。初期演示可只生成 Jira 草稿，实际创建和上传属于后续配置的连接器行为。

## Hooks 与显式操作

在验证过的客户端上，可通过 Hooks 调用保存进度、比较快照、刷新材料等程序。事件支持与载荷格式以目标环境为准；程序应可重复调用，避免一次工具操作触发多次相同写入或循环生成。

没有 Hooks 时，主 Agent 或用户可显式调用相同 Core 操作。会话结束事件可能缺失或进程异常退出，因此不能只在结束时保存全部内容。

Hooks 执行成功说明对应程序运行了，不等于语义判断一定正确。自动保存进度不自动确认设计决定。

## 错误与降级

| 情况 | 预期行为 |
| --- | --- |
| 不支持 Agent Plugin | 明确提示；开发验证期间可用显式 CLI，不声称已完成插件集成 |
| MCP 未启用 | 若允许可用 CLI；显示该环境实际支持范围 |
| Hooks 不可用 | 使用显式保存、检查和生成 Review |
| engineer-voice 未安装 | 保留原技术草稿，标明未做该改写 |
| 配置命令不存在 | 检查状态为执行错误 |
| 模块超时 | 保存错误和未完成状态，按模块策略继续或停止 |
| 相关记忆互相矛盾 | 展示差异并核对来源，不隐式选成项目规则 |

降级方式服务于开发和实际使用，但正式发布应明确最低支持环境与验收过的能力组合。
