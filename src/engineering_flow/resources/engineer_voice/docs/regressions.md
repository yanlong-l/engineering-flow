# 改写回归样例

以下均为构造文本，工具名、参数和场景只服务于样例，不代表实际部署或测试结果。每例给出允许的改写和必须拒绝的变化，不要求模型与参考输出逐字相同。围栏用于展示输入与参考输出，提交验收时只复制围栏内的正文；输入本身含有的行内代码等保护区仍不改。

## 1. 同一篇方案中的“基线”含义不同

**输入**

```text
## 采集与比较

新纳入的项目首次采集成功后，建立基线。每次比较都以用户选择的起始日成功快照为基线；不能用最近快照替代起始日缺失的数据。性能回归基线取 v3.2.0 在相同负载下的 P95 结果，延迟上升超过 8% 时拒绝发布。状态字段 `baseline_missing` 保持现有含义。
```

**可接受的改写**

```markdown
## 采集与比较

新纳入的项目首次采集成功后，保存这次采集结果。每次比较使用用户选择的起始日成功快照；起始日缺测时，不能用最近快照替代。发布前，将 P95 延迟与 v3.2.0 在相同负载下的结果比较，上升超过 8% 时拒绝发布。状态字段 `baseline_missing` 保持现有含义。
```

**应拒绝的改写**

- 将所有“基线”都换成“首次快照”，导致用户选择的比较起点被改掉。
- 将起始日缺测写成项目完全没有历史数据。
- 只说明一次含义，后文继续堆叠“建立基线、对齐基线、回归基线”，不检查各处指代。
- 修改 `baseline_missing`，或将“超过 8%”改成“达到 8%”。

**验收重点**：三种参照分开处理，比较时点、严格大于条件和机器标识保持。

## 2. “冻结”只暂停每日采集，仍保留复查

**输入**

```text
## 关闭后的采集

项目关闭后继续观察 3 天，指标未变化时冻结。冻结只暂停每日采集，每周仍复查一次；用户查看时可以刷新当前值。项目重新打开后恢复每日采集。接口状态值使用 `frozen`。
```

**可接受的改写**

```markdown
## 关闭后的采集

项目关闭后继续观察 3 天，指标未变化时暂停每日采集，仍保留每周一次的复查。用户查看时可以刷新当前值；项目重新打开后恢复每日采集。接口状态值使用 `frozen`。
```

**应拒绝的改写**

- 停止所有采集，或停止所有后台任务。
- 冻结后数据不可修改，或用户不能刷新当前值。
- 把每周复查改成每日复查，或把 3 天写成已确认的生产配置。
- 修改 `frozen` 的拼写。

**验收重点**：暂停的操作、继续的操作、手动刷新和恢复条件均保留，不把采集状态解释成数据只读。

## 3. 未确认不等于确认没有发生

**输入**

```text
检查代码可以确认查询使用了哪些字段，但不能据此确认线上索引已经核验。
```

**可接受的改写**

从代码可以确认查询使用的字段，无法仅凭这项检查确认线上索引已经核验。

**应拒绝的改写**

线上索引尚未核验。

**验收重点**：原文限制检查能支持的结论，没有断言核验尚未发生。

## 4. 标题不能将“为主”改成“只做”

**输入**

```text
## 一期以部门维度为主

默认只保存部门汇总。如果一期必须支持团队筛选，需要同时保存采集时的团队归属，是否纳入由评审决定。
```

**可接受的改写**

```markdown
## 一期以部门维度为主

默认只保存部门汇总。如果一期必须支持团队筛选，还需保存采集时的团队归属，是否纳入由评审决定。
```

**应拒绝的改写**

将标题改为“一期只做到部门维度”，或删除待评审的团队方案。

**验收重点**：标题、默认方案、条件分支与未决事项相容；原文标题无需修改。

## 5. 发布对象不能被改窄

**输入**

```text
批次校验成功后对外提供数据。页面与导出任务使用相同的完整批次，未完成的批次不可见。
```

**可接受的改写**

批次校验成功后对外提供数据。页面与导出任务读取相同的完整批次，未完成的批次不可见。

**应拒绝的改写**

校验成功后只向页面提供数据。

**验收重点**：使用方、发布条件和未完成批次的可见性不变。

## 6. 已准确的段落可以完整保留

**输入与可接受输出相同**

```text
## 重试限制

请求超时后最多重试 2 次，间隔 5 秒。认证失败不重试，直接返回 `AUTH_FAILED`。不建议在客户端叠加重试，以免放大请求量。
```

**应拒绝的改写**

- 为了制造差异，把标题改成长问句，增加“表达优化版”标记。
- 将“不建议”写成“禁止”，将“最多重试 2 次”解释为“总共请求 2 次”。
- 为满足“工程取舍”而编造压测数据或团队经历。

**验收重点**：零修改可以通过；不以修改数量或字数减少作为标准。

## 7. “冻结”也可能明确指禁止修改

**输入**

```text
评审开始后冻结配置，禁止修改其内容；已启动的采集任务继续运行。
```

**可接受的改写**

评审开始后，配置内容禁止修改，已启动的采集任务继续运行。

**应拒绝的改写**

评审开始后暂停采集任务。

**验收重点**：不能套用第 2 例的解释；同词需要按对象和上下文分别判断。
